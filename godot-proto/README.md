# godot-proto — минимальная проверка web-экспорта Godot 4.7.2

Сцена «слово на звук»:

- картинка (SVG) появляется твином;
- через 5 с появляется «рука» (подсказка);
- тап по картинке → слово «аист» (первая буква красная) + звук;
- затем частицы-награда и покачивание картинки.

Данные буквы лежат в `letters/a.tres` (Resource `LetterConfig` + `WordEntry`).

Сборка (Linux, headless; шаблоны экспорта 4.7.2 должны лежать в `~/.local/share/godot/export_templates/4.7.2.stable/`):

```bash
G=.godot-bin/Godot_v4.7.2-stable_linux.x86_64
$G --headless --path . --import
$G --headless --path . --export-release "Web" build/index.html   # однопоточный (thread_support=false), PWA вкл.
```

Проверка в headless Chrome:

```bash
PORT=28790 node tests/smoke.mjs     # THROTTLE=1 — сеть ~10 Мбит/с, RTT 40 мс; NOCOI=1 — без заголовков COOP/COEP
```

Результаты — в `../godot-analysis.md`, §1.1.

## Правила дизайна игр (25.10.2026)

**[`DESIGN_RULES.md`](DESIGN_RULES.md)** — обязательно для всех игр: §1 без автоподтверждения (пока ребёнок не выбрал верный ответ, игра его не подтверждает — только подсказки), §2 кнопки «назад»/«Далее»/крестик не перекрывают предметы ни на одном экране, §3 карточки по центру, цвет кнопки = цвет, который называет Аля; **§7 (26.10.2026) сцена 1 каждого урока — животное или предмет на букву урока приносит большую и маленькую букву** (урок «А» — аист, «У» — утка; буквы не называют и не разбирают; персонаж садится в верхней трети экрана не ближе ≈ 150 px от кнопок, его зона касания не перекрывает кнопки; «Далее» — после посадки; урок «А»: сцена 1 — `s01_stork` (аист приносит «А а» и садится в гнездо), колыбельная — сцена 2 `s02_intro`). Проверки: `PORT=<свободный> node tests/lesson.mjs` (без автоподтверждения, бездействие), `PORT=<свободный> node tests/layout.mjs` (7 экранов, включая iPhone 390×844).

## Урок «А»: навигация и подсказки (24.10.2026)

**Сайт = HTML-главная + урок в `lesson-a/`** (собирает `.github/workflows/pages.yml`):

- `/` — **главная с алфавитом**: папка `../web-home/` (обычные HTML/CSS/JS, ~45 КБ, Godot не грузится). Кубики — как на экране букв Godot (`menu/letters_menu.gd`): 33 кубика, палитра «мягкая радуга», шрифт DejaVu Sans Bold (подмножество А–Я, woff2), закрытые буквы приглушены и качаются от тапа; руки-подсказки на главной нет. В левом нижнем углу — маленькая «i» (кремовый круг, тонкий коричневый контур; место выбирает `placeInfo()` — слева от ряда кнопок, под рядом (телефон вертикально) или в пустой клетке последнего ряда, никогда не на кубиках) → HTML-страница «Как устроен Букварь» поверх главной (без Godot), тёмно-серый крестик / Esc / «назад» → буквы. Текст — общий для всех уроков, правится в одном файле `../web-home/info.html`. Экран — по макету `home_sections/mock_v3` (layout_v3, вариант B; раскладка в `layout()`): сверху сетка букв — на 4:3 всегда 7×5 (на 1024×768 кубик 100 px с y=28), на широких/горизонтальных 9×4 или 11×3, на узких/вертикальных 5×7 или 4×9, если кубик выходит крупнее на ≥12 % (высота ряда разделов учтена; неполный последний ряд — по центру); под ней ряд из 6 значков-разделов без подложек и табличек (`.rb`, `data-slot=1…6`, `data-section`: Алфавит, Слоги, Слова, Читаем, Мои наклейки, Язык жестов) с подписями под значками (PT Sans Bold, #3C3228, по центру). Все 6 — всегда в одну строку и масштабируются по ширине экрана: на 1024×768 кнопка 108, шаг 122, подпись 15 px; на 390×844 кнопка 52, шаг 58, подпись 11 px, «Мои / наклейки» и «Язык / жестов» в 2 строки. Сетка и ряд — по центру по X, на высоких экранах блок — по центру по высоте. Разделы пока только сжимаются при нажатии. Значки — `web-home/assets/home_N_key.png` (216×216, 256 цветов, ~37 КБ на все 6), пересобираются `python3 web-home/tools/make_home_icons.py <папка home_sections>`. Всё в любом окне без прокрутки. Ассеты главной пересобираются из финальной графики проекта: `python3 web-home/tools/make_assets.py` (из корня репозитория; Pillow, fonttools, brotli) — там же обновляется `core/app_icon.png`.
- Тап «А» → сразу отклик (кубик «нажимается» и пульсирует) → переход на `lesson-a/` с параметрами `debug`, `junior` (младший режим спит: без кнопки, только этим параметром), `hint_sec` (и `test`, `fast`, `audio` для тестов).
- `lesson-a/` — Godot. Без `?step` урок начинается **сразу со сцены `s02`** (экран для взрослого `s00` убран 26.10.2026; файл `steps/s00_parent_note.gd` остался в репозитории, но в `lesson.json` его нет) → `s02`…`s11`. Звук на iOS: если на странице урока ещё не было касания, s02 ждёт его (Аля пульсирует, состояние `wait_unlock`, `intro.unlock_tap`); в тестах этот шаг пропускается, `?gate=1` — включить.
- Крестик `ui_exit` справа вверху на `s01–s11` и «домой» в `s11` → назад на главную (`../`), параметры адреса сохраняются, кроме `step` (`main.go_home()`, через JavaScriptBridge).
- Ссылки сразу в урок: `lesson-a/?step=s01_stork` (или `s02_intro`, `s03_sing`…`s11_end`, или номер шага: `?step=6` → `s06_letter`, `?step=1` → `s01_stork`). `lesson-a/?step=letters_menu` — экран букв внутри Godot (для сравнения/отладки; в вебе он больше не главный). Вне веба (редактор) Godot по-прежнему стартует с экрана букв.
- Экран загрузки урока — своя оболочка `web/shell.html` (Export → Web → Custom HTML Shell): фон #ECE3D0, кубик «А», спокойная полоска прогресса, без логотипа Godot; заставка движка — просто фон #ECE3D0 (`boot_splash/show_image=false`).
- Рука-подсказка в уроке — всё в `data/common/hint.json` (`delay_sec` 20, картинка `sprite` = `ui_hint_hand`, пока её нет — `frames` `ui_hand_f1/f2`, `size`, кончик пальца `tip`, анимация `tap`/`drag`, `voice_every_shows`). Появляется после 20 с без касаний (пока звучит реплика, отсчёт стоит), **остаётся и мягко повторяет движение, пока ребёнок не сделает нужное**; касание цели / начало перетаскивания прячет её сразу, касание мимо — нет. Код — `core/main.gd` (`hint_start/hint_stop/hint_now`). В тесте/отладке: `?hint_sec=3`. На главной руки нет.
- Тесты (нужен `../.tools/node_modules/puppeteer-core`: `cd ../.tools && npm i puppeteer-core@23`):
  ```bash
  $G --headless --path . --export-release "Web" build/index.html
  bash tests/assemble_site.sh            # ../site = web-home/ + lesson-a/ (= build/), как в CI
  PORT=55783 node tests/home.mjs         # главная: без wasm/pck, вес, раскладка (сетка кубиков по экрану / 6 разделов в один ряд без наложений на кнопки, подписи, буквы и «i»; отдельно 1366×768, 1024×768, 768×1024, 390×844, 360×640) на 4:3/16:10/16:9/телефонах, кнопки, «i» → сведения → крестик, руки нет, «А» → урок (сразу s02) → крестик → домой
  PORT=55791 node tests/lesson.mjs       # весь урок: главная → «А» → s01 … s11 → «домой» → главная; крестик; подсказки
  ```

`.godot-bin/` — бинарник редактора, ~146 МБ. В архивы не включать.
