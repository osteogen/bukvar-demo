# godot-proto — минимальная проверка web-экспорта Godot 4.7.2

Сцена «слово на звук»:

- картинка (SVG) появляется твином;
- через 5 с появляется «рука» (подсказка);
- тап по картинке → слово «аист» (первая буква красная) + звук;
- затем частицы-награда и покачивание картинки.

Данные буквы лежат в `letters/a.tres` (Resource `LetterConfig` + `WordEntry`).

Сборка (Linux, headless; шаблоны экспорта 4.7.2 должны лежать в `~/.local/share/godot/export_templates/4.7.2.stable/`):

```bash
G=.godot-bin/Godot_v4.7.2-stable_linux.x86_64
$G --headless --path . --import
$G --headless --path . --export-release "Web" build/index.html   # однопоточный (thread_support=false), PWA вкл.
```

Проверка в headless Chrome:

```bash
PORT=28790 node tests/smoke.mjs     # THROTTLE=1 — сеть ~10 Мбит/с, RTT 40 мс; NOCOI=1 — без заголовков COOP/COEP
```

Результаты — в `../godot-analysis.md`, §1.1.

## Правила дизайна игр (25.10.2026)

**[`DESIGN_RULES.md`](DESIGN_RULES.md)** — обязательно для всех игр: §1 без автоподтверждения (пока ребёнок не выбрал верный ответ, игра его не подтверждает — только подсказки), §2 кнопки «назад»/«Далее»/крестик не перекрывают предметы ни на одном экране, §3 карточки по центру, цвет кнопки = цвет, который называет Аля. Проверки: `PORT=<свободный> node tests/lesson.mjs` (без автоподтверждения, бездействие), `PORT=<свободный> node tests/layout.mjs` (7 экранов, включая iPhone 390×844).

## Урок «А»: навигация и подсказки (24.10.2026)

**Сайт = HTML-главная + урок в `lesson-a/`** (собирает `.github/workflows/pages.yml`):

- `/` — **главная с алфавитом**: папка `../web-home/` (обычные HTML/CSS/JS, ~45 КБ, Godot не грузится). Кубики — как на экране букв Godot (`menu/letters_menu.gd`): 33 кубика, палитра «мягкая радуга», шрифт DejaVu Sans Bold (подмножество А–Я, woff2), закрытые буквы приглушены и качаются от тапа; руки-подсказки на главной нет. В левом нижнем углу — маленькая «i» (кремовый круг, тонкий коричневый контур; место выбирает `placeInfo()` — слева от кнопок, у левого конца черты или в пустой клетке последнего ряда, никогда не на кубиках) → HTML-страница «Как устроен Букварь» поверх главной (без Godot), тёмно-серый крестик / Esc / «назад» → буквы. Текст — общий для всех уроков, правится в одном файле `../web-home/info.html`. Экран — три полосы (раскладка в `layout()`): сверху пустая полоса 72·s под будущее меню; кубики (на 4:3 всегда 7×5, на широких — 9×4 или 11×3, если кубик выходит крупнее на ≥12 %; на 1024×768 кубик 100 px); тонкая бежевая черта #CDBFA6 по ширине сетки; внизу ряд из 6 пустых круглых кнопок (`.rb`, `data-slot=1…6`, 88·s px, не меньше 64 px, ободки — цвета палитры), пока только сжимаются при нажатии. Всё в любом окне без прокрутки. Ассеты главной пересобираются из финальной графики проекта: `python3 web-home/tools/make_assets.py` (из корня репозитория; Pillow, fonttools, brotli) — там же обновляется `core/app_icon.png`.
- Тап «А» → сразу отклик (кубик «нажимается» и пульсирует) → переход на `lesson-a/` с параметрами `debug`, `junior` (младший режим спит: без кнопки, только этим параметром), `hint_sec` (и `test`, `fast`, `audio` для тестов).
- `lesson-a/` — Godot. Без `?step` урок начинается **сразу со сцены `s01`** (экран для взрослого `s00` убран 26.10.2026; файл `steps/s00_parent_note.gd` остался в репозитории, но в `lesson.json` его нет) → `s01`…`s10`. Звук на iOS: если на странице урока ещё не было касания, s01 ждёт его (Аля пульсирует, состояние `wait_unlock`, `intro.unlock_tap`); в тестах этот шаг пропускается, `?gate=1` — включить.
- Крестик `ui_exit` справа вверху на `s01–s10` и «домой» в `s10` → назад на главную (`../`), параметры адреса сохраняются, кроме `step` (`main.go_home()`, через JavaScriptBridge).
- Ссылки сразу в урок: `lesson-a/?step=s01_intro` (или `s02_sing`…`s10_end`, или номер шага: `?step=5` → `s05_letter`). `lesson-a/?step=letters_menu` — экран букв внутри Godot (для сравнения/отладки; в вебе он больше не главный). Вне веба (редактор) Godot по-прежнему стартует с экрана букв.
- Экран загрузки урока — своя оболочка `web/shell.html` (Export → Web → Custom HTML Shell): фон #ECE3D0, кубик «А», спокойная полоска прогресса, без логотипа Godot; заставка движка — просто фон #ECE3D0 (`boot_splash/show_image=false`).
- Рука-подсказка в уроке — всё в `data/common/hint.json` (`delay_sec` 20, картинка `sprite` = `ui_hint_hand`, пока её нет — `frames` `ui_hand_f1/f2`, `size`, кончик пальца `tip`, анимация `tap`/`drag`, `voice_every_shows`). Появляется после 20 с без касаний (пока звучит реплика, отсчёт стоит), **остаётся и мягко повторяет движение, пока ребёнок не сделает нужное**; касание цели / начало перетаскивания прячет её сразу, касание мимо — нет. Код — `core/main.gd` (`hint_start/hint_stop/hint_now`). В тесте/отладке: `?hint_sec=3`. На главной руки нет.
- Тесты (нужен `../.tools/node_modules/puppeteer-core`: `cd ../.tools && npm i puppeteer-core@23`):
  ```bash
  $G --headless --path . --export-release "Web" build/index.html
  bash tests/assemble_site.sh            # ../site = web-home/ + lesson-a/ (= build/), как в CI
  PORT=55783 node tests/home.mjs         # главная: без wasm/pck, вес, раскладка (меню/кубики/черта/6 кнопок) на 4:3/16:10/16:9/телефонах, кнопки, «i» → сведения → крестик, руки нет, «А» → урок (сразу s01) → крестик → домой
  PORT=55791 node tests/lesson.mjs       # весь урок: главная → «А» → s01 … s10 → «домой» → главная; крестик; подсказки
  ```

`.godot-bin/` — бинарник редактора, ~146 МБ. В архивы не включать.
