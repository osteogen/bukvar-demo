# Урок «А», правки 27.10.2026 — ТЗ иллюстратору (графика-заглушки)

*27.10.2026. Всё перечисленное уже работает в godot-proto на заглушках. Готовый файл кладётся в `godot-proto/art/<папка>/<id>.png`
с тем же именем — код подхватит его сам (порядок поиска: `art/` → `art_provisional/` → `art_placeholder/`), правки кода не нужны.*

Общие требования:
- Сцена логически 1024×768; **размеры ниже — в пикселях файла @2x** (вдвое больше, чем на экране). Координаты сцены — логические (1024×768), центр предмета.
- PNG RGBA, прозрачный фон (кроме оговорённого), стиль — как утверждённые картинки урока (мягкая гуашь, тёплая палитра).
- Красный #D93A2B — только гласные / звуковой кружок. Никаких красных предметов на картинках.
- Карточки-картинки — на сплошной кремовой подложке #F7F0DE (её рисует код: в файле картинки фон прозрачный).
- Слои рта: 3 кадра `mouth_0` (закрыт), `mouth_1` (приоткрыт), `mouth_2` (открыт) — ими код делает липсинк по громкости голоса.
